# Online Examination System

## Project Description

Online Examination System is a web-based application that allows students
to attend examinations online and view their examination results.

## Features

- Student Login
- Online Examination
- Multiple Choice Questions
- Exam Submission
- Result Display
- JavaScript Exam Functionality
- Responsive Website Styling
